## 逐步检查

1. **进入往期页：已修复。** 原“本期”链接与带关闭图标的“往期”按钮指向同一地址；后者现仅标示当前页面。搜索框同时出现浏览器与自定义的两个清除按钮，现只保留一个。
2. **检索、阅读、返回：已修复。** 原先返回往期会丢失检索条件。现检索词保留在网址，阅读页返回时恢复该检索及原浏览位置。实测“周原”两条结果返回后仍保留；从归档下方卡片进入阅读再返回，恢复到原滚动位置。
3. **筛选与翻篇：已修复。** 原先目录筛为新石器三条，计数仍为十篇，正文仍显示旧石器文章，前后篇继续跳到其他时代。现显示“3 / 10篇”，当前文不在结果内时转至第一条，翻篇和方向键只在结果内移动；可一键清除筛选。无匹配时保留当前正文和清除入口，不跳出范围继续翻篇。本期检索原本还匹配了“上一篇／下一篇”的邻文标题，实测“清凉寺”误召回三条；现只检索本条标题、作者、正文、图注和原题名，结果为一条。
4. **切换刊期：已修复。** 以站内面板代替系统下拉菜单，显示日期、年份、篇数与当前刊期。桌面从页首按钮下展开，手机从底部展开。支持点击外部关闭、Esc关闭、方向键和Home/End选项移动；关闭后键盘焦点返回触发按钮。切换到首期后，完整刊名与“阅读中”状态正确。
5. **手机阅读与退出：已修复。** 阅读页重复的关闭按钮改为跨期检索入口。手机目录保留筛选结果和计数，选文后收起并把焦点移至文章标题。Esc只处理当前面板、目录或输入，不再直接跳离阅读页。
