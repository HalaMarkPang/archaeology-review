# 2026年11月23日加载优化

用户反馈加载偏慢，并指出左上角标识变化。核查发现：页面两张纸张纹理仍使用大尺寸PNG，合计4,689,342字节；多张封面也直接使用原始PNG。归档模板将旧版SVG标识替换成了字体“PQ”，已恢复旧SVG轮廓。

## 调整

纸纹保留原分辨率，改用WebP，合计165,772字节，减少96.5%。六张归档封面与两张正文配图生成适合网页的尺寸，通过srcset按屏幕宽度选用。正文查看原图继续使用原始文件，原有刊期JSON及原图未改动。

归档页两张纸纹与六张封面的文件体积合计由9,813,986字节降至792,998字节，减少91.9%；后者按每张最大的网页副本计算。实际请求量还受屏幕尺寸、图片延迟加载和浏览器缓存影响，此比例不是实测加载耗时的缩短比例。

首张封面优先加载，其余延迟加载；图片注明宽高，避免图片到达后改变布局。压缩资产与尺寸表直接提交，不增加线上构建依赖。CSS地址更新版本标记，使新版能取代浏览器已缓存的旧样式。

## 验证

69项测试通过，构建成功。浏览器检查1280×720及390×844：放大镜标识恢复，图片与纸纹正常，手机使用640像素宽的封面副本，无横向溢出；正文缩略图指向WebP，查看原图仍指向原PNG。未见控制台错误。

本次解决图片传输体积偏大和标识替换问题；GitHub Pages的网络访问速度仍随访问环境变化，不以一次加载时间作普遍速度承诺。
